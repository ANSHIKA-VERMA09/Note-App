# Notes App

Simple full stack notes application using React and Node.js.

## Features

- Add notes
- Edit notes
- Delete notes


## Backend Setup

cd server

npm install

npm start

Runs on:
http://localhost:5000

## Frontend Setup

cd client

npm install

npm run dev

Runs on:
http://localhost:5173

## Tech Stack

Frontend:
- React
- Axios

Backend:
- Node.js
- Express

## Assumptions

- Notes are stored in memory / JSON
- Simple UI focused on functionality
